# 🍎 מעקב קלוריות יומי

אפליקציית web בעברית לחישוב צריכת קלוריות יומית — לפי **תיאור טקסט** או **צילום של האוכל**.
האפליקציה עובדת **חינם לגמרי ללא מפתח** (ניתוח טקסט מקומי ומאגר מזון מובנה), ובאופן אופציונלי גם עם OpenAI לניתוח חכם וניתוח תמונות. הנתונים נשמרים מקומית בדפדפן בלבד.

## תכונות
- 🆓 **ניתוח טקסט מקומי ללא מפתח** — זיהוי מאכלים, כמויות ומשקלים בגרמים מתוך משפט חופשי (לדוגמה: "2 ביצים, 150 גרם עוף ופרוסת לחם מלא")
- 🔎 מאגר מזון מובנה רחב (~115 מאכלים) עם חיפוש מהיר ובורר כמויות (ללא צורך ב-API)
- ✍️ הוספת מזון בעזרת טקסט חופשי בעברית
- 📷 צילום / העלאת תמונה של מנה והערכת קלוריות אוטומטית *(דורש מפתח OpenAI)*
- 📊 סיכום יומי: קלוריות, חלבון, פחמימה ושומן
- 📈 היסטוריה של 7 הימים האחרונים עם גרף וממוצע
- 🎯 הגדרת יעד קלורי יומי עם מד התקדמות
- 💾 שמירה מקומית (localStorage) — יומן נפרד לכל יום, וייצוא/ייבוא גיבוי
- 📱 PWA — ניתן להתקין בנייד ולעבוד גם ללא חיבור לאינטרנט
- 🔒 מפתח ה-API (אם משתמשים) נשמר רק בדפדפן שלך

## הפעלה
1. פתחו את התיקייה `calorie-tracker`.
2. *(אופציונלי)* לניתוח חכם יותר או לניתוח תמונות — הזינו מפתח OpenAI API דרך כפתור ההגדרות (⚙️).
   ניתן להפיק מפתח בכתובת <https://platform.openai.com/api-keys>. **ללא מפתח הטקסט והמאגר עובדים חינם.**
3. הריצו שרת מקומי (חובה ל-PWA ולמצלמה):

   ```powershell
   cd calorie-tracker
   python -m http.server 5500
   ```

   ואז גלשו אל <http://localhost:5500>. בנייד/דפדפן נתמך ניתן ללחוץ "הוסף למסך הבית" כדי להתקין.
